# 🍔 Website Pemesanan Makanan Online

Repositori ini berisi berkas dan kode untuk **Website Pemesanan Makanan Online**. Proyek ini dibuat sebagai **tugas UI/UX saat kelas 10**,

---

### 📌 Tentang Proyek
Proyek ini dirancang untuk memberikan alur dan tampilan pemesanan makanan yang simpel serta ramah pengguna

---

### ✨ Fitur Utama
* 📋 **Tampilan Menu:** Menampilkan daftar pilihan makanan dan minuman.
* 🛒 **Alur Pemesanan:** Desain antarmuka pemesanan yang sederhana dan mudah dipahami.
